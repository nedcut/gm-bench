# Offline illustrative evidence

Generated with public seeds 701 and 702, two repeats, one season, and the
`scripted-rules-v1` fixture. See [the report](report.md) and
[the protocol and commands](../../docs/memory_experiment.md).

`manifest.json` records the preregistration and exact source digest. `cells.json`
contains the eight cell summaries; `analysis.json` contains the paired analysis.
This is a compact illustration, not a raw run directory: full traces and replay
ledgers are generated by the documented command, not committed here. The report's
references to individual `cell.json` files correspond to entries in `cells.json`.

The recorded source commit is the implementation commit, before this generated
example was added. The experimental source bytes are identical. Report timestamps,
git provenance, hash and measured timing may differ on reproduction; the paired
score and tool-use differences must agree. No model was called. These results
demonstrate implementation behavior, not an LLM benefit.
